# Math Misconception Detector for Netlify
This repository contains the Math Misconception Detector application configured for Netlify deployment.

## Deployment Instructions

1. Fork this repository to your GitHub account
2. Log in to your Netlify account
3. Click 'Add new site' > 'Import an existing project'
4. Connect to your GitHub and select this repository
5. In the deploy settings, set the publish directory to 'dist'
6. Click 'Deploy site'

## Features

- Camera-based math work analysis
- File upload option for math work images
- Gemini Flash 2.0 AI integration
- Misconception detection and feedback
- History tracking

## Backend API

The application uses a FastAPI backend deployed at: https://math-misconception-api-ntuiyndx.fly.dev/
